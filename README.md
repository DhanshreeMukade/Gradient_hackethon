# Gradient_hackethon
🚀 Project Update | E-Commerce Data Analysis

Excited to share our E-Commerce Data Analysis project developed as part of the Data Analytics Hackathon conducted by Gradient! 📊

Our team worked on the Olist Brazilian E-Commerce dataset to solve a real-world business problem: understanding marketplace performance and identifying factors associated with customer dissatisfaction.

🔍 What we analyzed:
• Order & sales trends
• Delivery performance
• Customer satisfaction & review scores
• Product categories
• Seller performance
• Payment behavior
• Regional patterns

🛠️ Tools & Technologies:
Python | Pandas | Excel | Power BI | Git & GitHub

📈 We also created an interactive Power BI dashboard to present our key findings and make the analysis easy to understand.

💡 Key Insight:
Late deliveries showed a strong association with lower customer satisfaction, with average ratings of 2.55 ⭐ for late orders vs 4.28 ⭐ for on-time/early orders.

We’ve also organized our project work and code on GitHub as part of our collaborative development process. 🤝

A great experience of learning, analyzing, building, and collaborating as a team!
